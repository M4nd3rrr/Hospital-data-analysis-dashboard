# Hospital Data Analysis & Dashboard

## 📊 Project Overview

This project analyzes a synthetic healthcare dataset containing approximately 55,000 hospital records.

The purpose of the project was to explore hospital admissions, patient demographics, medical conditions, revenue, healthcare providers, and admission trends using Microsoft Excel.

The analysis was developed as a practical data analytics portfolio project.

---

## 🛠️ Tools Used

* Microsoft Excel 2021
* Power Query
* Power Pivot
* DAX
* PivotTables
* Excel Charts
* Slicers

---

## 🎯 Analysis Performed

### 🏥 Top 10 Hospitals

Analyzed the **10 hospitals with the highest number of patient admissions** to identify hospitals with the greatest patient volume.

### 👨‍⚕️ Top 10 Doctors

Created a chart showing the **10 doctors with the highest number of patient records**, allowing comparison of patient volume across doctors.

### 💰 Median Revenue by Medical Condition

Analyzed **median revenue across different medical conditions** to compare the typical revenue associated with each condition.

### 🛏️ Length of Stay

Analyzed the **number of days patients stayed in the hospital** to understand patient length-of-stay patterns.

### 👥 Age Group Analysis

Patients were classified into different age groups:

* Children
* Adults
* Older Adults

A chart was created to show the **count of patients within each age group**.

### 📅 Monthly Admission Trends

Created a monthly trend analysis showing the **number of hospital admissions over time** to identify changes and patterns in admission volume.

---

## 🎛️ Interactive Dashboard Filters

The dashboard includes interactive slicers that allow users to filter the analysis dynamically.

### Year Slicer

A year slicer was created covering **2019–2024**, allowing users to analyze the dataset for individual years.

### Admission Type Slicer

Users can filter the dashboard based on different **admission types**.

### Insurance Provider Slicer

Users can filter the analysis by **insurance provider** to explore differences in hospital activity across providers.

These slicers interact with the dashboard charts, allowing users to explore different segments of the dataset without manually changing the underlying data.

---

## 📈 Dashboard Features

The final dashboard includes:

* KPI and summary analysis
* Top 10 hospitals
* Top 10 doctors
* Median revenue by medical condition
* Length-of-stay analysis
* Patient age-group distribution
* Monthly admission trends

This project demonstrates how Excel can be used to transform a large healthcare dataset into an interactive analytical dashboard.
